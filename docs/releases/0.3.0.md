Clarity brings a native, UI-framework-independent interface to `vue2-smart-datatable` for Vue 2.6 and 2.7 applications.

## Install and explore

```sh
npm install vue2-smart-datatable@0.3.0
```

```ts
import { SmartDataTable } from 'vue2-smart-datatable'
import 'vue2-smart-datatable/styles.css'
```

[Live demo](https://reydi-dev.github.io/vue2-smart-datatable/) · [Local/API example](https://reydi-dev.github.io/vue2-smart-datatable/#data) · [npm package](https://www.npmjs.com/package/vue2-smart-datatable/v/0.3.0)

## What's new

- Native Clarity desktop tables, mobile cards, filters, column chooser, export controls and table states.
- Vue is the only peer dependency (`>=2.6.14 <3`); built-in controls require no Vuetify instance or icon font.
- Direct page navigation with Latin, Persian and Arabic digits. A jump commits on Go or Enter; typing does not request intermediate pages.
- Independent viewport detection, inline SVG icons, explicit light/dark themes, RTL and keyboard interactions.
- Preserved provider, controlled-state, event, slot and exporter contracts.
- An updated public demo with the approved order composition and a separate local/API example in the same application.

## Upgrading from 0.2.x

Read the [Clarity upgrade guide](https://github.com/reydi-dev/vue2-smart-datatable/blob/v0.3.0/docs/clarity-upgrade.md) before upgrading. This pre-1.0 minor release changes UI integration:

- Migrate CSS and DOM tests that target Vuetify internals to native table selectors.
- Convert Vuetify palette expressions and icon-registry aliases to supported colors and explicit icon definitions. Custom `mdi-*` icons still need a host-provided font unless replaced by SVG.
- Pass an explicit `mobileBreakpoint` if your application used customized Vuetify thresholds.
- Ensure native modal dialog support (`showModal()`) or provide a compatible polyfill for the column chooser.
- Keep Vuetify in applications that use it elsewhere; remove it only when the old table was its sole consumer.

The order demo's status tabs and compact summaries are application-owned slots; they are not automatically added to every table installation. Vue 3 support remains future work.

## Validation and scope

The stable package's JavaScript, CSS and declarations match `0.3.0-rc.1`. Published-package installation and clean consumer checks passed. The subsequent demo CI passed package validation, browser tests and all four Vue 2.6/2.7 native/Vuetify consumer combinations on Node 18.

See [consumer validation](https://github.com/reydi-dev/vue2-smart-datatable/blob/main/docs/consumer-validation.md) and [release readiness](https://github.com/reydi-dev/vue2-smart-datatable/blob/main/docs/release-readiness.md) for test scope and recorded limitations. The earlier Package Lab resize-width assertion was accepted by maintainer manual review, not converted into an automated pass; additional manual functional checklist results remain unreported. Chrome was exercised; Safari/Firefox and screen-reader certification are not claimed.
