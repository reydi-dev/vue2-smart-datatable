# Roadmap

The immediate goal is a stable, well-documented `0.1.0` release for Vue 2.7 and Vuetify 2.6 applications.

## Before 0.1.0

- validate the API through the live demo and release candidates;
- expand provider, slot, accessibility, and browser coverage;
- test the packed artifact in independent consumer projects;
- finalize the npm package identity and release automation.

## Possible later work

- multiple sort clauses;
- reusable advanced-filter composition;
- saved table-state presets;
- additional exporter adapters maintained outside the core bundle;
- documented calendar and localization integrations;
- performance work for very large local datasets.

Items are intentionally not assigned to a version until their API and maintenance cost are understood.
